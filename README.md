# Python and Beyond

Python をゼロから学び、その先（機械学習、AI、因果推論、アルゴリズムなど）へ進むための、自学自習用の教材です。
Google Colab で開いて、そのまま動かせます。

（準備中です。教材は順に追加していきます。）

## 教材

| 教材 | 内容 | 前提 |
|---|---|---|
| 教材1「Python」 | 第1部「基礎」（最初から順に）と、第2部「もっと知る」（興味のあるものだけ） | なし |
| 教材2「Python の使い道」 | ゲーム、絵、音、地図、ホームページなど、Python でできることを試す | 教材1 第1部 |
| 教材3「機械学習」 | 回帰、分類、クラスタリングなど（scikit-learn） | 教材1 第1部 |
| 教材4「ディープラーニングと生成 AI」 | ニューラルネットワーク、画像、言語モデル（PyTorch） | 教材3 |
| 教材5「因果推論」 | 相関と因果、回帰分析、傾向スコア、差の差など | 教材3 |
| 教材6「アルゴリズムとデータ構造」 | 探索、並べ替え、グラフ、動的計画法など | 教材1 第1部 |
| 教材7「データベースと SQL」 | データの取り出し、集計、表をつなぐ（SQLite） | 教材1 第1部 |

全部をやる必要はありません。興味のあるところまで、自分のペースで進めてください。

## 分からないときは

AI（Colab の Gemini、ChatGPT、Claude など）に質問しながら進めることを前提にしています。聞き方は、教材1「Python」第1部の2回目で説明します。
